H4NGELIC — MASTER FOUNDATION

Öffnen
1. Auf GitHub im Branch feat/master-foundation die Datei
   docs/previews/h4ngelic-preview.html öffnen.
2. „Download raw file“ wählen, die HTML-Datei speichern und auf einem
   Computer im Browser öffnen. Die GitHub-Codeansicht führt die Website nicht aus.
3. Bei portfolio-preview.zip zuerst entpacken, dann die HTML-Datei öffnen.

Aktuelle Version
- Eine gemeinsame NAAVI steht unten mittig, ohne INDEX-Dropdown im Header.
- Home führt von 00 bis 04/04 und zurück; Work von 01 bis 03/03; About zeigt 01/01.
- Kleine Hero-Steuerung unten links; keine Berlin-Kopfzeile oder mixed-media-Zeile.
- WORKS: tattoos mit on skin, flashes und leerem 3d model; jewellery;
  more mit digital artworks vor analog photography. Keine Kategorie-Trennlinien.
- About bleibt ein fließender Absatz mit kleinem Einzug und kleinerem MORE ABOUT.
- HOW TO REACH YOU akzeptiert E-Mail, Instagram oder Telefonnummer.
- VISIT steht auf allen Seiten neben h4ngelic. Routenwechsel zählen keinen Besuch.
- Horizontale Karussells unterstützen Ziehen, Wischen, Trackpad, Tastatur und Pfeile.
- Vergrößerte Fotos schließen per erneutem Klick, Klick daneben oder Escape.
- Digital Artworks zeigt das gelieferte Original sofort, ohne Ink-Reveal.
- Dezente Hover-Effekte bleiben innerhalb der Seitenränder.

Es wurden noch keine bestätigten Tattoo-, Flash- oder Analog-Fotos geliefert.
Diese Archive zeigen deshalb 0 / 0 und „archive in progress.“, keine Ersatzbilder.
Eigene Arbeiten lassen sich zentral in src/data/artworks.js ergänzen; siehe docs/CONTENT.md.

Das akzeptierte Other-Side-Moshing bleibt erhalten. Taste 4 mindestens eine Sekunde
halten; zurück mit 333 oder erneutem Halten von 4. Auf Touch-Geräten den h4-Schalter
viermal antippen, zum Zurückkehren dreimal. Eingabefelder vorher verlassen.
Reduzierte Bewegung wird respektiert.

Alle lokalen Website-Assets sind eingebettet. Interne Seiten verwenden hier
#-Adressen. Diese Datei ist keine öffentliche Produktionsseite. Echter Anfrageversand
benötigt einen konfigurierten Mail-Dienst und ist in der Offline-Datei nicht verfügbar.
