H4NGELIC — WEBSITE UPDATE

Öffnen
1. Auf GitHub im Branch feat/website-completion die Datei
   docs/previews/h4ngelic-preview.html öffnen.
2. „Download raw file“ wählen und die gespeicherte HTML-Datei auf einem
   Computer in einem aktuellen Browser öffnen. Die GitHub-Codeansicht
   selbst führt die Website nicht aus.
3. Bei portfolio-preview.zip zuerst entpacken, dann die HTML-Datei öffnen.

In dieser Version prüfen
- Die Startseite zeigt kein INDEX. Auf den Unterseiten bleibt INDEX erhalten.
- Die Kapitel-Navigation führt durch Contact bis zum finalen h4 und zurück.
- About-Text und MORE ABOUT stehen links unter ihrer Überschrift.
- Lange Rubriken und Pfeile bleiben auch beim Hover innerhalb der Seitenränder.
- Digital Artworks zeigt das Original sofort, ohne Ink-Reveal oder Scrollmaske.
- Die Work-Leiste lässt in Welt 4 das beschädigte Material durchscheinen.
- Tattoo-, Flash- und Analog-Archive besitzen native horizontale Karussells:
  Pfeile, Tastatur, Ziehen, Wischen, Trackpad und Shift + Mausrad.

Es wurden noch keine bestätigten Tattoo-, Flash- oder Analog-Fotografien
geliefert. Diese Archive zeigen deshalb einen ehrlichen leeren Zustand
mit 0 / 0, keine erfundenen Bilder. Eigene Arbeiten lassen sich zentral
in src/data/artworks.js ergänzen; siehe docs/CONTENT.md.

Das akzeptierte Other-Side-Moshing bleibt erhalten. Taste 4 mindestens eine
Sekunde halten; zurück mit 333 oder erneutem Halten von 4. Auf Touch-Geräten
den h4-Schalter viermal antippen, zum Zurückkehren dreimal. Eingabefelder
vorher verlassen. Reduzierte Bewegung wird respektiert.

Alle lokalen Website-Assets sind eingebettet; interne Seiten verwenden
in dieser Offline-Vorschau #-Adressen. Die HTML-Datei ist keine öffentliche
Produktionsseite. Echter Anfrageversand benötigt den konfigurierten
Mail-Dienst und ist in der heruntergeladenen Datei nicht verfügbar.
