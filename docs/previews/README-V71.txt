H4NGELIC — V7.1 / P0-VORSCHAU

Öffnen
1. Auf GitHub die Datei docs/previews/h4ngelic-preview.html im Branch
   feat/v71-memory-mosh öffnen. Falls nötig, bei GitHub anmelden.
2. „Download raw file“ wählen und die Datei als h4ngelic-preview.html speichern.
   Die GitHub-Codeansicht selbst zeigt die Website nicht an.
3. Die gespeicherte HTML-Datei auf einem Computer in einem aktuellen Chrome
   oder Firefox öffnen. Bei portfolio-preview.zip zuerst das ZIP entpacken
   und anschließend die darin enthaltene HTML-Datei öffnen.

Alle benötigten Website-Assets sind eingebettet. Die Vorschau funktioniert
lokal über file://; interne Seiten verwenden dafür #-Navigation. Ein
Webserver ist zum Ausprobieren nicht erforderlich.

Ausprobieren
- Taste 4 mindestens eine Sekunde halten, um The Other Side zu aktivieren.
- Zum Zurückkehren 333 innerhalb von zwei Sekunden eingeben oder erneut
  die 4 mindestens eine Sekunde halten. Eingabefelder vorher verlassen.
- Auf Touch-Geräten den h4-Modusschalter viermal innerhalb von zwei Sekunden
  antippen; zum Zurückkehren dreimal. Der Haltehinweis am Seitenende lässt
  sich ebenfalls eine Sekunde lang drücken.
- Mausbewegung, Klicks, Scrollen und interne Seitenwechsel ausprobieren:
  Der beschädigte Bildspeicher entwickelt sich innerhalb der aktiven Sitzung
  weiter, ohne automatisch zum ursprünglichen Hintergrund zurückzukehren.
  Eine neue Aktivierung darf eine neue Komposition erzeugen.

Diese Version enthält ausschließlich die P0-Arbeit am persistenten
Memory-Mosh und seiner Leistung. Bei aktivierter Systemeinstellung für
reduzierte Bewegung bleibt das beschädigte Hintergrundbild statisch.

Die HTML-Datei ist eine lokale Vorschau, keine öffentliche Produktionsseite.
Das Anfrageformular kann offline keine Nachricht versenden. Messwerte aus
automatisierten Browserprüfungen ersetzen keinen Test auf einem echten Handy.
