# Editing the horizontal archive

The carousel uses the published projects in `src/data/artworks.js`. All eight supplied tattoo photographs remain in their original order. The renderer derives its total from the filtered project list; the live controller derives its cycle length, wrap index and counter from the mounted slides. There is no fixed five- or eight-photo cycle.

To add a photograph, place its original file in `public/images/tattoos/`, then add an entry in `src/data/artworks.js` with a unique ID, `category: 'tattoos'`, `published: true` and an image containing its real path, descriptive `alt`, original `width` and `height`. Remove an entry, or set `published: false`, to remove it from the row. Run `npm run images:optimize` and rebuild; the existing pipeline supplies responsive WebP previews. Original files remain unchanged.

`src/carouselSettings.js` is the single carousel tuning file. Each exported field has a JSDoc explanation and the complete current table is in `PROJECT_PLAN.md`. `autoDrift: true` and `autoScroll: 0.3` run the approved rightward loop at about 18px/s. `hoverPause: true` stops it while a fine pointer or keyboard focus is inside. `cameraDistance: 900`, `depthScale: true`, `edgeRotation: 12` and `edgeScaleFloor: 0.92` tune the CSS-only perspective. `spacing` controls the card gap; `inertia: 0.05` controls finite drag momentum.

`scrollCapture: 'none'` deliberately keeps vertical wheel and touch input native. `wheelSensitivity` remains documented for compatibility but no longer drives page scrolling or card movement. Drag and swipe take over the horizontal position, then the ambient loop resumes after momentum settles. `neighborDisplacement` and `hoverStraighten` tune the shared hover treatment; `pointerLabel` remains false.

Additional fields tune the reserved expansion space, viewport clearances, hover lift, neighbour shift, drag threshold, velocity limits and announcements. The shared `src/inline-artwork-expand.js` controls activation, viewport fitting, full-resolution loading, outside-click/second-click collapse and Escape. It preserves the image's layout slot and uses no modal, WebGL surface or page-wide zoom. Reduced motion keeps the row static with instant states.
