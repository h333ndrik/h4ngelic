### Changed assertions

- **F18:** icon profile checks and the mode cursor contract assert one image and
  hotspot per mode; no hover/active cursor variants.
- **F19:** resting-card geometry, flat transforms, viewport wheel scope, touch
  escape, expansion thresholds and drift performance expectations.
- **F20:** poster/FCP/CLS profiles; interior routes remove the poster preload;
  Cold Work/About/Home Contact must not request the Three.js scene, font or
  texture. The standalone reduced-motion suite now waits for
  `is-poster-static` and expects the poster instead of a visible WebGL canvas.
- **F21:** recognition line asserted at `21px` and at the measured
  branding↔INDEX centre rather than the page centre; the mobile footer counter
  is reached by scrolling its local cluster and a native tap, with discovery
  asserted through `is-discovered` plus visible opacity.
- **F22:** hero bar expects translation with constant opacity and exact reduced
  endpoints.
- **F23:** Contact offset, intro gap, mobile zero offset, single column and
  target sizes.
- **F24:** default mode duration and metadata 1400 → 900; UV phase samples
  162/198 ms; native animation asserted at 900 ±150 ms; wall-clock capture and
  cleanup stay below 2500 ms. The pixel proof uses the typography band and a
  two-level ambient-dither tolerance.
- **F25:** subordinate heading scan accepts the category heading with its
  optional `rubric-category-heading` class. The canonical search term remains
  `archive-category-heading`.
- **F26:** rubric child headings are asserted as plain text with zero links and
  arrows; `/work/more` h1 is `page-heading sr-only`; offline navigation opens
  Flash/Digital directly by route because their headings are no longer links.
- **F27:** archive title/filter/cross-link text is `on skin`; Home, NAAVI, global
  INDEX, URLs, IDs and `data-work-group` remain `tattoos`.
- **V23:** offscreen static titles are read with `textContent`, because
  `content-visibility: auto` makes `innerText` empty before scrolling.
- **Standalone native:** honors `CHROMIUM_PATH` like the other browser suites.
